# Облигационный конструктор с автообновлением котировок

Статический сайт (index.html) + ежедневное обновление данных с Московской биржи через GitHub Actions.
Никаких серверов и платных сервисов.

## Что внутри
- `index.html` — приложение (работает и без интернета: внутри встроен файл офз.xlsx).
- `data.json` — котировки. Сначала это данные из вашего файла от 20.10.2026, дальше их перезаписывает скрипт.
- `scripts/update_data.py` — забирает ОФЗ (площадка TQOB) и корпоративные облигации (TQCB) из ISS API Мосбиржи.
- `ratings.json` — рейтинги корпоративных выпусков (ISS их не отдаёт). Название выпуска → рейтинг.
- `.github/workflows/update.yml` — запуск скрипта по будням в 19:00 по Москве.

## Установка (около 20 минут)
1. Зарегистрируйтесь на github.com и создайте **публичный** репозиторий, например `bonds`.
2. Загрузите в него все файлы из архива вместе с папками `scripts` и `.github` (кнопка Add file → Upload files; папку `.github` перетаскивайте как есть, у неё скрытое имя).
3. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
4. Settings → Actions → General → Workflow permissions → **Read and write permissions** → Save.
5. Вкладка Actions → слева «Update bond data» → Run workflow. Через минуту откройте запуск и посмотрите лог.
   Нормальный лог: `TQOB: получено ... выпусков`, `TQCB: получено ... выпусков`, `Облигаций в data.json: ...`.
6. Сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/bonds/`. Статус вверху страницы показывает время последнего обновления.

## Что проверить после первого запуска
- Скрипт читает колонки ISS по названиям. Если Биржа поменяла формат, он остановится и напишет, каких колонок не хватает, а `data.json` не тронет.
- Строка «Без рейтинга» в логе показывает корпоративные выпуски, которых нет в `ratings.json`. Такие выпуски скрыты во всех профилях риска. Если их много, значит названия ISS отличаются от названий smart-lab: добавьте нужные пары в `ratings.json` (формат `"Название": "AA-"`) или вставьте таблицу со smart-lab в блок «Обновить котировки» на странице, это тоже работает.
- Название выпуска в ISS может отличаться от названия на smart-lab. Бумаги в «Моём плане» ищутся по названию, поэтому после перехода на данные Биржи у части корпоративных выпусков может появиться пометка «нет в файле». У ОФЗ названия совпадают.
- GitHub отключает расписание в репозиториях без активности 60 дней. Если обновления остановились, зайдите в Actions и включите workflow снова.

## Ограничения
- Пропускаются выпуски с номиналом не 1000 ₽ (амортизируемые), индексируемые и амортизируемые ОФЗ, выпуски без цены или с нулевым купоном (кроме плавающих ОФЗ, их купон считается по прогнозу ключевой ставки в приложении).
- Доходность берётся из ISS, если её нет, считается по денежным потокам. Она может отличаться от smart-lab в десятых долях процента.
- Данные Биржи могут идти с задержкой, это не торговый терминал и не инвестиционная рекомендация.
